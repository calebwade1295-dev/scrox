# Scrox Android starter

This is a starter Expo / React Native project for Scrox.

## What is included
- Black and red Scrox branding with a lightning-bolt mark
- Demo feed tabs and sample posts
- Like toggle
- Home, Search, Create, Inbox, and Profile navigation placeholders

## Important
This is a front-end starter, not a complete TikTok-style service. It does not yet include real accounts, video uploads/hosting, comments, messaging, moderation, or a backend.

## Android APK build
The `eas.json` file includes an APK preview profile. Building requires Expo EAS Build and an Expo access token. See the guided steps in ChatGPT before running a cloud build.
